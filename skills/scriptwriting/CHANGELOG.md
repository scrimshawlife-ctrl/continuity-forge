# Changelog — scriptwriting

## 0.2.0 — 2026-07-28
### Major Upgrade
- Rebuilt as production-grade Narrative Engineering System per full specification.
- Modular phases (0-13) with entry conditions, output schemas, quality gates, failure states.
- Explicit request routing + operating modes (DEVELOP, DRAFT, DIAGNOSE, REVISE, POLISH, CONTINUITY, PRODUCTION, ADAPT).
- Core operating principles codified (Structure Before Pages, Drama Is Change Under Pressure, Behavior Before Explanation, Causality Over Sequence, Approved Material Is Canon, etc.).
- Anti-slop quality gates A–L with detectors and fixes.
- Scene contracts, continuity ledger, revision records as first-class artifacts.
- Format-specific logic (feature, TV pilot, short, vertical, audio, animation, games).
- Provenance labels (OBSERVED/INFERRED/SPECULATIVE/NOT_COMPUTABLE).
- JSON schemas for project-brief, character, scene-contract, continuity-ledger, revision-record.
- Supporting references, templates, and evals/ cases.
- Diagnosis rubric (1-5) with evidence requirement.
- Validation tests documented with expected behaviors.
- SKILL.md kept compact; deep guidance moved to references/.

### Preserved from 0.1.0
- Concrete AI prompt templates (logline, scene, dialogue, YouTube structure).
- Emphasis on visual/subtext/action over explanation.
- Iteration, read-aloud, and humanizer pairing.
- Basic format awareness.

### Breaking / Changes
- Linear "Procedure" replaced by conditional modular workflow.
- Strong requirement for foundations before drafting.
- Explicit canon locking and continuity auditing mandatory for revisions.
- Anti-slop gates now enforceable rules, not suggestions.

### Files
- SKILL.md (compact)

- schemas/ (additional)
- templates/ (feature, short, pilot starters)
- evals/ (rubric + cases)
- CHANGELOG.md
