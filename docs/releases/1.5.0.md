# Continuity Forge 1.5.0

**Handoff release — shot breakdown + continuity export**

| Field | Value |
|-------|--------|
| Version | `1.5.0` |
| Tag | `v1.5.0` |
| Base | Built on frozen **`v1.4.0`** long-form kernel |
| Package | `[project].version` in `pyproject.toml` |
| API | `/health` → `"version": "1.5.0"` |
| Breakdown schema | `cf.breakdown.v1` |
| Breakdown claim | `shot_breakdown_with_continuity_not_production_film` |
| Production-validated | **No** |

First **forward** release after the v1.4.0 baseline freeze. Adds the explicit handoff path: paste/import screenplay → shot-by-shot breakdown with continuity → machine-readable JSON (connectors) and Markdown export, plus an automated harness.

---

## What 1.5.0 adds

### Product path

```text
Screenplay (Fountain / FDX)
  → compile → continuity ledger → shot contracts
  → BreakdownPackage (cf.breakdown.v1)
  → JSON file / REST / MCP  ·  optional Markdown
```

| Surface | How |
|---------|-----|
| **UI** | **Build breakdown** → shot table + **Download breakdown JSON/MD** |
| **CLI** | `continuity-forge breakdown script.fountain --out out` |
| **REST** | `POST /v1/breakdown` · `POST /v1/breakdown/markdown` |
| **MCP** | `build_breakdown` · `build_breakdown_markdown` |
| **Harness** | `make handoff` / `scripts/handoff_harness.py` |

Guide: [`docs/HANDOFF.md`](../HANDOFF.md)

### Package fields (connector contract)

- Scenes, entities, setup/payoff links  
- Shot rows: slugline, label, constraints, entity names, state hashes  
- Provenance: `source_hash`, IR / ledger / shots hashes, `package_hash`  

---

## Inherited from 1.4.0 (still true)

- M0–M7 mock controlled-proof path  
- Long-form operator scale (nav, virtualize, invalidation, incremental, cost, events)  
- Dual-lane honesty: execution vs production readiness  
- Providers remain **PROPOSED** until human approval  
- `make validate` is the default gate  

Baseline freeze notes: [`1.4.0.md`](1.4.0.md)

---

## Explicit non-claims

Do **not** treat 1.5.0 as:

- Production film or ACCEPTED media  
- Production-validated Temporal fleet  
- Live paid provider readiness  
- Billing / multi-tenant OAuth product  

Breakdown is **structure + continuity only**. Mock proof remains optional and separate.

## Install / pin

```bash
git clone https://github.com/scrimshawlife-ctrl/continuity-forge.git
cd continuity-forge
git checkout v1.5.0
python3.12 -m venv .venv && source .venv/bin/activate
pip install -U pip && pip install -e '.[dev]'
make validate
make handoff
make breakdown   # sample → out/*.breakdown.json
make ui          # http://127.0.0.1:8080/ → Build breakdown
```

## Support policy

| Stream | Policy |
|--------|--------|
| **`v1.4.0`** | Immutable baseline freeze |
| **`1.4.x`** | Patches only on the freeze story (preserve 1.4 contracts) |
| **`v1.5.0`** | Handoff release (this document) |
| **`1.5.x`** | Bugfixes on handoff path without breaking `cf.breakdown.v1` |
| **`1.6+`** | Production stack, live providers, SSE, etc. |

Breaking changes to `cf.breakdown.v1` should bump schema and minor/major version.
