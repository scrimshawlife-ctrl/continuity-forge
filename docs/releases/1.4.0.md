# Continuity Forge 1.4.0

**Baseline freeze — mock controlled-proof operator kernel**

| Field | Value |
|-------|--------|
| Version | `1.4.0` |
| Tag | `v1.4.0` |
| Package | `[project].version` in `pyproject.toml` |
| API | `/health` → `"version": "1.4.0"` |
| Claim | `controlled_proof_not_production_ready` |
| Production-validated | **No** |

This release freezes a coherent, tested baseline after M0–M7, post-1.0 foundations,
audit hardening (phases 1–3), and long-form operator scale (phase 4). Forward work
should land on `main` as **1.5+** (or carefully backported **1.4.x** patches only).

---

## What this release is

A **deterministic cinematic-production kernel** and **model-agnostic harness** that:

1. Compiles Fountain/FDX → validated Production IR  
2. Builds continuity ledger + shot contracts  
3. Runs durable kernel pipeline with idempotency + checkpoints  
4. Exposes MCP/REST/Hallmark UI for operators  
5. Generates **PROPOSED** mock media candidates via repair loop  
6. Emits a versioned **controlled proof** receipt (not production film)

**Default gate:** `make validate` (`scripts/validate_m0.py` — ruff, mypy, pytest, coverage floors).  
**Also in CI:** packaging wheel/sdist smoke; Postgres/MinIO integration smoke skeleton.

## Explicit non-claims

Do **not** treat 1.4.0 as:

- Production film or ACCEPTED media pipeline  
- Production-validated Temporal cluster  
- Live paid provider readiness (OpenAI/Runway/etc. are env-gated stubs)  
- Multi-tenant OAuth / enterprise IAM  
- Billing or spend-approval product  
- Feature-length production readiness marketing  

Providers remain **`PROPOSED`** until an explicit human approval path elevates them.  
Kernel owns canon. Agent checkpoints and chat are never film state.

## Install (baseline)

```bash
git clone https://github.com/scrimshawlife-ctrl/continuity-forge.git
cd continuity-forge
git checkout v1.4.0
python3.12 -m venv .venv && source .venv/bin/activate
pip install -U pip && pip install -e '.[dev]'
make validate
make proof    # mock controlled proof → out/
make ui       # http://127.0.0.1:8080/
```

Full setup: [`docs/SETUP.md`](../SETUP.md).

## Authority invariants (must not weaken after freeze)

From `AGENTS.md` and architecture:

- Source screenplay is immutable input  
- Deterministic kernel output is canon only after validation  
- Provider/model output is always PROPOSED until reviewed  
- Mutations use envelope + lease + idempotency where required  
- Controlled proof never implies production readiness

## Compatibility & support policy

| Stream | Policy |
|--------|--------|
| **v1.4.0 tag** | Immutable baseline; use for bisect and operator handoff |
| **1.4.x** | Bugfix / security patches only that preserve 1.4 contracts |
| **1.5+** | Production stack, live providers, SSE, behavior/deploy assumption changes |

Breaking authority or IR schema changes should bump minor (or major) and call out migration.
